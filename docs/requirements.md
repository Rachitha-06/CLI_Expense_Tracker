# Functional & Non-Functional Requirements

## Functional

1. Add expense with validation
2. Record income separately
3. View transactions (sortable, paginated)
4. Edit transaction by ID
5. Delete transaction with confirmation
6. Manage categories (default + custom)
7. Search (partial, case-insensitive)
8. Filter (date, category, type, amount, payment, tags)
9. Financial summary dashboard
10. Monthly / yearly / custom-range reports
11. Budget set / edit / status / warnings
12. Recurring rules (weekly/monthly)
13. CSV export
14. Backup & restore

## Non-Functional

- Python 3.11+
- Standard library only
- Decimal for money
- Atomic JSON writes
- Graceful error handling
- Unit tests with temporary directories
- Clear documentation
